第一次使用？获取访问密钥
  1. 打开 GitHub 密钥创建页，登录你的网站所属账号。
  2. 选择 Only select repositories，只勾选 personal-site。
  3. 在 Repository permissions 中将 Contents 设为 Read and write，设置有效期并生成密钥。
  4. 把生成的密钥粘贴到上方，点击“连接网站”。

如果提示缺少作品目录，说明新版上传功能尚未发布到仓库。
